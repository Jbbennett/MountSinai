# MountSinai

 Ecommerce store for a clothing company.
 Deals with sending out reminders, displaying items for sale, and transfers money.

## Installation

1. Clone repository.
2. Navigate to project directory.
3. Install dependencies with `npm install`.

## Usage

To use this project, follo these steps:

1. Install the live server extension on vs code.
2. Press "Go live"
